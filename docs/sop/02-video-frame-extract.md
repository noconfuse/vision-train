# SOP-2 视频抽帧

> 把项目中的视频切成可用图片，并按需导入到训练数据集。

## 2.1 目标

视频抽帧适合这些场景：

- 从监控或生产视频中挑出训练图片
- 先批量抽图，再人工筛选有价值的帧
- 把选中的帧导入某个数据集，继续标注和训练

## 2.2 开始前

建议先确认三件事：

- 已有一个项目
- 项目中已经放入待处理视频
- 已明确这些图片最终要进入哪个数据集

如果目标数据集还没有准备好，也可以先只做抽帧，等筛选完成后再导入。

## 2.3 视频放在哪里

视频文件统一放在项目目录下：

```text
projects/<project>/videos/
```

常见格式都可以直接使用，例如 `mp4`、`mov`、`avi`、`mkv`、`webm`。

## 2.4 抽帧会产生什么结果

抽帧分成两步：

1. 先从视频中生成一批临时图片
2. 再把你确认需要的图片导入到目标数据集

这意味着：

- **抽帧完成，不等于已经进入数据集**
- 抽出的图片会先进入任务结果，方便你筛选和删除
- 只有执行“导入到数据集”后，图片才会真正进入训练数据集目录

## 2.5 如何使用

### 选择抽帧策略

抽帧时通常要设置两项内容：

| 项目 | 说明 |
| --- | --- |
| 抽帧策略 | 可按时间间隔抽帧，或按目标张数抽帧 |
| 抽帧数值 | 按时间间隔时表示秒数；按目标张数时表示希望抽出的总张数 |

如果你只是先做素材筛选，建议先用较稀疏的抽帧设置，避免一次生成太多重复图片。

### 等待任务完成

抽帧任务会进入任务中心。你可以在任务中心查看：

- 当前状态
- 进度
- 错误信息

### 审核抽出的图片

任务完成后，先检查抽出的图片是否符合预期：

- 删除明显重复、模糊或无效的帧
- 保留有目标对象、场景变化明显的帧
- 再把保留的图片导入目标数据集

### 导入到数据集

导入后，图片会进入目标数据集的训练图片目录。此时它们还没有标签，后续需要继续标注。

## 2.6 文件会写到哪里

### 视频原文件

```text
projects/<project>/videos/
```

### 抽帧任务的临时结果

```text
projects/<project>/temp_tasks/<task_id>/images/
```

### 导入后的训练图片

```text
projects/<project>/training/<dataset_name>/train/images/
```

> 导入图片时不会自动生成标签文件。如需训练，请继续完成标注。

## 2.7 删除任务意味着什么

删除抽帧任务时，系统会同时清理这次任务产生的临时文件。

如果你已经把图片导入到数据集，导入后的数据集图片不会受影响；
如果还没导入，删除任务后这些临时图片也会一起消失。

## 2.8 常见问题

| 现象 | 处理建议 |
| --- | --- |
| 视频没有出现在列表里 | 确认视频已放入当前项目的 `videos/` 目录，文件名和格式正常 |
| 抽帧完成但看不到可用图片 | 打开任务结果确认是否真的抽出了图片；如果数量异常少，换更密的抽帧设置再试 |
| 导入后数据集里没有标签 | 这是正常现象，抽帧只负责生成图片，不负责标注 |
| 生成了很多相似图片 | 适当加大抽帧间隔，或导入前先筛掉重复帧 |

# SOP-2 视频抽帧

> 上传项目视频，抽取候选帧，筛选后导入到新数据集或已有数据集中。

## 2.1 适合什么场景

视频抽帧适合下面几类工作：

- 从监控、生产或实验视频中抽取训练图片
- 先批量取样，再人工筛选有效帧
- 把一段视频快速沉淀成新的训练数据集

## 2.2 开始前

建议先确认：

- 已经进入正确的项目
- 你知道这些图片最终要进入哪个数据集
- 机器已安装 `ffmpeg`

如果你还没有目标数据集，也没关系。当前版本支持把抽帧结果直接导入为新数据集。

## 2.3 当前版本怎么上传视频

视频页已经提供直接上传入口，不需要必须手工往目录里放文件。

推荐做法：

1. 切换到当前项目的“视频”视图
2. 点击“上传视频”
3. 选择本地视频文件
4. 上传完成后，视频会出现在列表中

如果你更习惯手工管理文件，也可以把视频直接放到：

```text
projects/<project>/videos/
```

常见格式如 `mp4`、`mov`、`avi`、`mkv`、`webm` 都可以使用。

## 2.4 一次完整抽帧流程

当前推荐流程如下：

1. 在视频卡片中点击“抽帧构建数据集”
2. 选择抽帧策略
3. 启动任务
4. 在右侧“当前项目任务”中查看进度
5. 任务完成后打开审查弹窗
6. 勾选保留的图片
7. 导入到新数据集或已有数据集
8. 系统自动跳转到对应数据集详情页继续处理

## 2.5 抽帧策略怎么选

当前常用的两种策略：

| 策略 | 含义 |
| --- | --- |
| 按时间间隔抽帧 | 每隔一段时间抽一张 |
| 按目标张数抽帧 | 希望这段视频大约抽出多少张 |

经验建议：

- 先做筛选素材时，设置稀一点，避免出现大量相似帧
- 想覆盖动作变化或状态切换时，可以适当加密
- 视频很长时，先做一轮保守抽帧，更容易控制后续审查成本

## 2.6 任务完成后怎么审查

抽帧完成后，图片不会立刻进入数据集，而是先进入任务结果区供你筛选。

建议重点清理：

- 明显模糊的帧
- 几乎重复的相邻帧
- 没有目标物或没有业务价值的帧

保留下来的图片再导入数据集，后续才更适合继续标注和训练。

## 2.7 导入到数据集时会发生什么

当前版本支持两种导入方式：

- 导入到一个新数据集
- 导入到当前项目下已有数据集

导入后：

- 图片会写入目标数据集
- 系统会补齐标准 YOLO 目录结构与 `dataset.yaml`
- 新导入的图片默认没有人工标签
- 页面会自动跳转到对应数据集详情页

> 抽帧只负责生成图片，不会自动替你完成人工标注。

## 2.8 任务列表怎么看

视频页右侧会显示“当前项目任务”，只展示这个项目下的抽帧任务。

你可以在这里看到：

- 当前状态
- 进度
- 抽帧数量
- 导入结果
- 错误信息

如果需要看全局任务，可以从侧边栏底部菜单进入“任务中心”。

## 2.9 删除任务意味着什么

删除抽帧任务时，系统会清理该任务对应的临时抽帧结果。

影响如下：

- 如果你还没有导入数据集，这批临时图片会一起消失
- 如果你已经导入数据集，数据集中的图片不会被回删

所以建议在删除任务前，先确认需要保留的图片是否已经导入。

## 2.10 文件会写到哪里

典型路径如下：

```text
projects/<project>/videos/                    # 视频原文件
projects/<project>/temp_tasks/<task_id>/...   # 抽帧任务临时结果
projects/<project>/training/<dataset_name>/   # 导入后的目标数据集
```

## 2.11 常见问题

- **视频上传后没出现在列表里？** 先确认你当前所在的是正确项目，再检查文件是否上传成功。
- **抽帧完成但图片很少？** 说明抽帧策略偏稀，可以调小间隔或提高目标张数重试。
- **导入后为什么还不能训练？** 因为只有图片，没有标签；需要继续走 [SOP-3 数据标注](03-annotation.md)。
- **抽出的图片太多太像？** 先在任务结果里筛选，再导入，不要把冗余帧直接灌进数据集。

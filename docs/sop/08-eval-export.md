# SOP-8 评估、导出与部署模板

> 在训练工作流下完成模型评估、模型导出与部署模板生成，覆盖从"模型可用"到"上线可部署"的最后一公里。

## 8.1 目标

让读者理解：

- 测试评估的边界与指标含义
- 模型导出与部署模板的本质区别
- 不同部署格式的语义与适用场景
- 部署模板与导出产物的解耦关系

## 8.2 前置条件

- 已存在训练工作流与可用权重，参见 [SOP-7 模型训练](07-train.md)。
- 数据集存在 `test` split（评估时）。
- 导出与模板生成各自满足对应执行条件（参见 §8.4 / §8.5）。

## 8.3 业务动作总览

| 动作 | 输入 | 输出 | 与导出关系 |
| --- | --- | --- | --- |
| 测试评估 | 工作流 + test split | 评估指标 | 不产生新产物 |
| 模型导出 | 工作流 + 源权重 | 导出产物（ONNX / OpenVINO / TensorRT / PT） | 是"导出" |
| 部署模板 | 工作流 + 源权重或导出产物 | 模板包（FastAPI / Python SDK / 批处理） | 是独立任务，与导出解耦 |

## 8.4 测试评估

### 发起评估

数据集存在 `test` split 时可以发起一次评估任务，评估指标随训练任务持久化，**不会产生新的模型产物**。

### 评估指标

| 指标 | 含义 | 关注场景 |
| --- | --- | --- |
| `Precision` | 预测为正的样本里真的是正的比例 | 更怕误报时关注 |
| `Recall` | 实际为正的样本里被找出来的比例 | 更怕漏检时关注 |
| `mAP50` | IOU ≥ 0.5 的平均精度 | 宽松口径下的整体效果 |
| `mAP50-95` | IOU 0.5 → 0.95 的平均精度 | 严格口径下的整体效果 |
| `pose_mAP50` / `pose_mAP50-95` | `pose` 任务的对应指标 | 关键点评估专用 |

## 8.5 模型导出

### 导出格式

| 格式 | 适用场景 | 备注 |
| --- | --- | --- |
| `onnx` | 通用部署环境 | 未确定部署环境时优先 |
| `openvino` | Intel 设备 | 适合 Intel CPU / iGPU |
| `tensorrt` | NVIDIA GPU | 依赖主机环境支持 |

### 参数 / 字段含义

| 字段 | 含义 | 备注 |
| --- | --- | --- |
| `format` | 导出格式 | 上述三种之一 |
| `imgsz` | 导出模型输入尺寸 | 与训练尺寸可不同 |
| `half` | FP16 半精度 | 减小体积，部分环境提升推理速度 |
| `int8` | INT8 量化 | 进一步压缩，但可能带来精度损失 |
| `device` | 导出执行设备 | 部分格式强依赖 GPU |

> `half` 与 `int8` 不能同时开启；`tensorrt` 在不支持的环境会被禁用。

### 导出记录

导出记录随工作流持久化，包含状态 / 进度 / 产物路径 / 文件大小 / 下载入口。同一工作流可保留多次导出尝试，**多次导出之间不互相覆盖**。

## 8.6 部署模板

### 模板类型

| 模板类型 | 入口点 | 适用 |
| --- | --- | --- |
| `fastapi_service` | `app.main:app` | 容器化 HTTP 推理服务 |
| `python_sdk` | `sdk.predictor:Predictor` | 嵌入现有 Python 服务 / 业务代码 |
| `batch_processor` | `runner.main:main` | 离线批处理任务 |

### 模板源

模板任务是独立任务，与导出完全解耦。源模型可以是：

| 源类型 | 描述 | 备注 |
| --- | --- | --- |
| `best` | 当前工作流最佳权重 | 默认首选 |
| `last` | 当前工作流最后权重 | 适合继续微调 |
| `export:<task_id>` | 已导出的 ONNX / OpenVINO / TensorRT 产物 | 用于目标部署格式 |

### 参数 / 字段含义

| 字段 | 含义 | 备注 |
| --- | --- | --- |
| `template_type` | 模板类型 | 上述三种之一 |
| `source` | 模板源 | `best` / `last` / `export:<task_id>` |
| `source_format` | 源模型格式 | `pt` / `onnx` / `openvino` / `engine` |
| `source_model_path` | 源模型路径 | 后端根据 source 推导 |
| `imgsz` | 推理输入尺寸 | 与训练尺寸可不同 |
| `half` | FP16 半精度 | 仅 ONNX / OpenVINO 有效 |
| `int8` | INT8 量化 | 仅 OpenVINO 有效 |

### 模板记录

模板记录随工作流持久化，与导出记录同层级。模板记录可单独删除，**不影响导出产物**。

### 任务执行模式

模板任务与训练 / 导出共享同一套任务调度与进度轮询机制：

- 任务进度由 worker 子进程回写到任务表。
- 任务中心可以统一查看所有模板任务。
- 模板任务不引入独立的实时通道，与项目既有模式保持一致。

## 8.7 数据落点

```text
projects/<project>/training_outputs/<dataset_name>/<run_id>/
├── export/<export_task_id>/         # 模型导出产物
└── template/<template_task_id>/     # 部署模板产物
    ├── manifest.json                # 模板元数据
    ├── app.py / sdk.py / runner.py  # 模板入口（依类型）
    └── requirements.txt             # 模板依赖
```

## 8.8 失败排查

| 现象 | 排查方向 |
| --- | --- |
| 不能发起测试评估 | 数据集缺少 `test` split |
| TensorRT 选项不可用 | 当前主机环境不支持 TensorRT |
| 导出 INT8 后效果变差 | 不要直接替代普通版本，建议额外保留 |
| 模板生成停滞 | 确认任务已进入任务中心且 worker 已注册对应任务类型；模板任务遵循项目既有轮询机制 |
| 模板执行报 ImportError | 检查模板包是否完整解压，`runner/__init__.py` 是否包含 `Predictor` 导出 |

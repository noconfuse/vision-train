# SOP-1 项目管理

> 项目是数据、训练、评估、导出、部署模板、任务中心等所有能力的根上下文。本 SOP 描述项目的语义边界、生命周期与数据落点。

## 1.1 目标

让读者理解：

- 项目在系统里代表什么
- 项目下沉淀了哪些数据
- 创建 / 编辑 / 删除 / 切换项目会引发什么副作用

## 1.2 前置条件

- 已经在系统内登录（参见 [快速开始](../guide/quickstart.md)）。
- 决定目标项目根目录的位置，默认指向环境变量 `VISION_TRAIN_PROJECTS_DIR` 指定的位置。

## 1.3 项目是什么

一个项目对应项目根目录下的一个独立目录，它承载：

- 训练数据集
- 视频原文件与抽帧任务结果
- 训练、评估、导出、部署模板的产物
- 该项目下的训练工作流、任务记录

数据、视频、训练等视图只展示“当前项目”下的内容。

## 1.4 数据落点总览

```text
projects/<project_name>/
├── training/                  # 数据集根目录
│   └── <dataset_name>/
├── training_outputs/          # 训练 / 评估 / 导出 / 部署模板产物
├── videos/                    # 视频原文件
└── .description               # 项目描述（仅 UI 展示）
```

## 1.5 参数 / 字段含义

| 字段 | 含义 | 备注 |
| --- | --- | --- |
| `name` | 项目名 | 字母 / 数字 / `_` / `-`；禁止 `.` 开头与保留名 |
| `description` | 项目描述 | 仅 UI 展示，不影响训练逻辑 |
| `path` | 项目绝对路径 | 仅内部使用，对外 DTO 输出存储引用协议 |
| `created_at` / `updated_at` | 时间戳 | 基于文件系统时间 |

## 1.6 失败排查

| 现象 | 排查方向 |
| --- | --- |
| 创建失败提示名称不合法 | 检查项目名是否仅含允许字符、是否以 `.` 开头、是否与保留名重名 |
| 列表里看不到新建项目 | 确认 `VISION_TRAIN_PROJECTS_DIR` 指向正确根目录，且目录名合规 |
| 改名后任务产物无法打开 | 确认产物内的绝对路径引用；当前不会自动迁移 |
| 删除后想恢复 | 默认无法恢复；删除前应自行备份 |

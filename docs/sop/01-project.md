# SOP-1 项目管理

> 在 Vision Train 中创建、切换、编辑和删除项目。项目是所有数据、任务和训练工作流的根上下文。

## 1.1 项目是什么

在 Vision Train 里，一个项目对应项目根目录下的一个独立目录。这个目录承载：

- 训练数据集
- 视频原文件与抽帧任务结果
- 训练、评估、导出产物
- 该项目下产生的任务与工作流记录

你后续看到的数据集页、视频页、训练页，全部都依赖“当前项目”。

## 1.2 当前界面里怎么管理项目

项目操作集中在左侧侧边栏：

- 选择项目：切换当前工作上下文
- 新建项目：创建一个新的空项目
- 编辑项目：修改名称或描述
- 删除项目：彻底删除整个项目目录

> 数据集导入不属于“项目管理”本身，而是在项目内的“数据集列表”里完成，详见 [SOP-3 数据标注](03-annotation.md)。

## 1.3 创建项目

创建项目时，系统会在项目根目录下初始化标准结构，并立即把它显示在侧边栏中。

典型步骤：

1. 在侧边栏点击“新建项目”
2. 输入项目名称，按需填写描述
3. 创建成功后，系统自动切换到这个项目

创建完成后，主区域通常还是空的，这是正常情况。接下来需要继续：

- 导入现成数据集
- 或上传视频并抽帧生成数据集

## 1.4 目录结构

典型目录结构如下：

```text
projects/<project_name>/
├── training/                  # 数据集目录
│   └── <dataset_name>/
│       ├── dataset.yaml
│       ├── train/{images,labels}
│       ├── val/{images,labels}
│       └── test/{images,labels}
├── training_outputs/          # 训练 / 评估 / 导出产物
├── videos/                    # 视频原文件
└── .description               # 项目描述（可选）
```

说明：

- `training/` 下每个子目录就是一个可训练数据集
- `training_outputs/` 保存训练工作流的产物
- `videos/` 用于保存上传或手工放入的视频文件
- `.description` 只用于 UI 展示，不影响训练逻辑

## 1.5 项目命名建议

建议项目名只使用：

- 字母
- 数字
- 下划线 `_`
- 短横线 `-`

同时避免：

- 以 `.` 开头
- 过长或包含空格、中文路径分隔含义字符
- 与系统保留目录重名

如果命名不符合规则，系统会在创建或重命名时提示。

## 1.6 编辑项目

当前版本常见编辑操作有两类：

- 改项目名称
- 改项目描述

需要注意：

- 改名本质上是移动项目目录
- 如果该项目下正有训练、评估、导出等任务在运行，不建议此时改名
- 描述只影响 UI 展示，不会改动训练协议

## 1.7 删除项目

删除项目是高风险操作，会直接清理整个项目目录，通常包括：

- 所有数据集
- 所有训练、评估、导出产物
- 所有视频文件
- 该项目下的相关中间文件

删除前建议先确认两件事：

1. 是否已经导出需要保留的数据集或模型
2. 是否还有任务正在运行

> 如果你只想删除某一个数据集，不要删项目，应在数据集列表里删除该数据集。

## 1.8 切换项目后会看到什么

切换到某个项目后，主页会在“数据集”和“视频”两个视图之间切换：

- 数据集视图：看当前项目下所有数据集，并进入标注或训练
- 视频视图：看当前项目下所有视频和抽帧任务

侧边栏底部的用户菜单中还可以进入“任务中心”，查看全局任务状态。

## 1.9 手工放置项目目录

如果你已经在磁盘上准备好了项目目录，也可以直接按标准结构放到项目根目录下，再刷新系统识别。

例如：

```bash
mkdir -p projects/my_proj/{training,training_outputs,videos}
```

然后把已有数据集或视频放入对应目录中。

## 1.10 常见问题

- **新建的项目没有出现在列表里？** 先确认它位于 `VISION_TRAIN_PROJECTS_DIR` 指定的项目根目录下，且目录名符合规则。
- **能不能把项目放到其他磁盘？** 可以，通过环境变量调整项目根目录，详见 [运行配置](../deploy/config.md)。
- **项目创建后为什么还是空的？** 因为项目只是容器，接下来还需要导入数据集或上传视频。
- **删除项目后能恢复吗？** 默认不能，删除前应先自行备份。

# SOP-6 类别顺序调整

> 修改 `dataset.yaml::names` 中的类别 ID 顺序，并把所有 `labels/*.txt` 中的 class id 同步重写。

## 6.1 入口语义

类别顺序调整作用于**当前数据集**，可在任意阶段触发（不必等到训练）。

## 6.2 为什么需要

YOLO 用 class id 标识类别，**模型输出层和 id 是绑定的**。如果你的 `names` 顺序是：

```yaml
names: [helmet, no_helmet, person]
```

而 `labels/*.txt` 里大量图都是 `no_helmet`（id=1），训练时 `no_helmet` 占据输出层第 2 个通道。

如果你想把 `no_helmet` 改成 id=0（更突出"未戴安全帽"这个负样本），必须：

1. 修改 `names` 的顺序
2. 把所有 `labels/*.txt` 里的 `1` 改成 `0`，把 `0` 改成 `1`
3. （可选）更新导出的 `nc` 字段

> Vision Train 帮你把 1+2 一步完成，3 自动随之更新。

## 6.3 操作步骤

1. 触发类别顺序调整，会看到当前类别顺序，以及建议的目标顺序
2. **拖拽**或填入 `order` 数组，按你想要的新顺序排列
3. 选择要重写的 splits（默认全选 `train/val/test`）
4. 确认 → 后端会：
   - 写回 `dataset.yaml`（`names`、`nc`）
   - 遍历每个 `labels/<split>/*.txt` 重写 class id
   - 报告改动文件数 / 行数 / 跳过的文件数

## 6.4 删除整个类别

类别删除作用于**当前数据集**：

1. 列出当前所有类别
2. 选择要删除的类别（按 id 或按名字）
3. 选择 splits
4. 确认 → 后端会：
   - 从 `names` 数组中移除该条目
   - 遍历 labels，**删除**包含该 id 的所有行
   - 若删除后该行变空，**整张图标签**被删除（不会删除图片）
   - 更新 `nc`

> ⚠️ **删除操作会丢掉这些行**，不可撤销。建议先 [SOP-5 弱类补偿](05-class-rebalance.md) 重新生成子集，而不是直接删。

## 6.5 行为细节

- **不重命名**：工具只改 ID 顺序，不改类别名。如果你要改名字，请直接编辑 `dataset.yaml`，然后 [SOP-3 标注](03-annotation.md) 中重做标注。
- **不支持合并**：想把两个旧类合并成新类，请先 [SOP-5 弱类补偿](05-class-rebalance.md) 生成新子集时手动处理。
- **操作前备份**：虽然系统会尽量安全处理，但类别顺序调整和删除类别都会直接改动数据集内容，建议先导出或复制一份数据集备份。

## 6.6 验证

完成后：

1. 重新打开数据预览 → 顶部 chips 应显示新顺序
2. 抽样打开几张图的标注器，确认 id 已切换

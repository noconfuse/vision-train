# SOP-5 弱类补偿采样 (Class Imbalance Optimization)

> 对**类别分布不均**的训练集，生成一个**新的子数据集**，让目标类样本数大幅提升、非目标类按比例保留。

## 5.1 为什么需要

YOLO 训练在严重不平衡的数据集上会偏向多数类，导致少数类（"弱类"）漏检。常见场景：

- 工厂异常动作检测：99% 正常 vs 1% 异常
- 安全帽检测：90% 已佩戴 vs 10% 未佩戴
- 缺陷检测：99.9% OK vs 0.1% NG

弱类补偿 = **重复采样弱类** + **下采样多数类** + **数据增强**，让训练时各类样本"看起来"差不多。

## 5.2 入口语义

弱类补偿操作作用于**当前数据集**（数据集已在 [SOP-3](03-annotation.md) 中完成标注），生成一个**新数据集**。

## 5.3 参数说明

| 参数                | 默认       | 说明                                                                 |
| ------------------- | ---------- | -------------------------------------------------------------------- |
| 源数据集            | 当前选中   | 必须已存在并按 SOP-3 完成标注                                        |
| 目标数据集名        | 必填       | 新生成的数据集，会落到 `training/<new_name>/`                       |
| 目标类别（多选）    | 必填       | 哪些类算"弱类"                                                       |
| 目标类重复倍数      | 8          | 每张目标类图片被复制几次                                              |
| 非目标类保留比例    | 0.35       | 0~1，非目标类图片保留多少比例（防止多数类消失）                       |
| 是否复制 val/test   | true       | eval 集也按相同规则采样                                              |
| 是否平衡 eval       | false      | 若 true 则额外控制 eval 集中目标类比例                                |
| 目标比例            | -          | 当"是否平衡 eval=true"时生效                                         |
| 随机种子            | 42         | 复现性                                                               |
| 是否启用水平翻转    | true       | 水平翻转作为最廉价增强                                                |
| 是否启用垂直翻转    | false      | 默认关（多数场景垂直翻转会破坏语义）                                  |
| 颜色抖动            | 0.2        | HSV jitter 强度，0 表示不抖                                          |
| Dry-run             | false      | 只返回**预估**的样本数，不实际生成文件                                |

## 5.4 输出结构

```text
projects/<proj>/training/<new_name>/
├── dataset.yaml
├── train/
│   ├── images/      # 弱类复制 + 非目标类下采样 + 可选翻转
│   └── labels/      # 同步复制（flip 时坐标镜像）
├── val/             # 同样处理
└── test/            # 同样处理（如存在）
```

新数据集自动出现在数据集列表中。

## 5.5 增强策略细节

### 5.5.1 重复采样弱类

- 选中类别为 `[A, B]` 的图片会被复制 `target_repeat` 次
- 复制后**源文件不变**，仅生成新文件 `xxx__aug0.jpg` / `xxx__aug1.jpg` …

### 5.5.2 非目标类下采样

- 非目标类图片以 `non_target_keep_ratio` 概率保留
- 比例过低（< 0.2）会显著降低多数类权重，建议从 0.3~0.5 起步

### 5.5.3 翻转

- 水平翻转：bbox 中心 `x_center → 1 - x_center`
- 垂直翻转：bbox 中心 `y_center → 1 - y_center`（默认关闭）

### 5.5.4 颜色抖动

- `H ± hsv_h * 0.5`，`S * (1 ± hsv_s)`，`V * (1 ± hsv_v)`
- 不改变 bbox，只改像素

## 5.6 推荐参数

| 数据规模        | 弱类样本数 | 推荐 `target_repeat` | 推荐 `non_target_keep_ratio` |
| --------------- | ---------- | -------------------- | ---------------------------- |
| < 500           | < 50       | 16~24                | 0.2~0.3                      |
| 500~5000        | 50~500     | 8~12                 | 0.3~0.5                      |
| 5000~50000      | > 500      | 4~8                  | 0.4~0.6                      |

> 弱类样本 < 30 时，单纯重复采样收益有限，**建议先做自动标注或人工扩样**。

## 5.7 与训练的联动

生成的子数据集自动带上 `dataset.yaml`，在 [SOP-7 训练](07-train.md) 时直接可选。同时**强烈建议**勾选训练面板中的 **针对不平衡数据集优化**，后端会自动启用 Cosine LR + Mosaic + MixUp + 较强增强，详见训练 SOP。

## 5.8 常见错误

| 错误                                          | 原因与解决                                                |
| --------------------------------------------- | --------------------------------------------------------- |
| `目标类 samples = 0`                          | 选中的类别在源数据集中没有任何图；先确认类别 ID 是否对得上 |
| `缺少 images/train 目录`                      | 源数据集结构异常，回到 SOP-1 检查                          |
| 新数据集 `annotation_rate < 1`                | 源数据集本身标注不全；先回到 SOP-3 补标注                  |

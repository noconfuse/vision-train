# SOP-7 模型训练

> 选择数据集和模型，完成一次训练，并在任务中心持续查看状态与结果。

## 7.1 目标

训练功能适合这些场景：

- 首次训练一个新数据集
- 基于历史训练结果继续迭代
- 针对某个问题数据集快速验证参数效果

## 7.2 开始前

开始训练前，建议确认：

- 当前数据集已经可以训练
- 训练图片和标签基本完整
- 已选定要使用的预训练模型或历史模型
- 当前设备有足够的时间和资源完成本次训练

如果数据集还缺大量标签，建议先完成标注或先做一版小规模验证，不要直接投入长时间训练。

## 7.3 训练前需要做什么

### 选择模型

训练页会展示两类模型：

- 官方预设模型
- 当前项目的历史训练模型

如果是第一次训练，通常从官方预设开始；
如果是迭代优化，通常从项目历史模型继续更高效。

### 设置基础参数

训练时最常用的是这些参数：

| 参数 | 作用 |
| --- | --- |
| 训练轮数 | 决定最多训练多久 |
| 批次 | 每次送入多少图片 |
| 图像尺寸 | 训练时统一使用的输入尺寸 |
| 初始学习率 | 决定模型开始学习的步长 |
| 冻结层数 | 适合做迁移学习时减少前面层的改动 |

### 视情况使用增强参数

如果你的数据量较小、场景变化较大，或者希望提升泛化能力，可以再调整增强参数。

如果你只是做第一版基线训练，建议先用较简单的配置跑通，再逐步增加增强强度。

### 使用批次校准

训练页提供**批次校准**，会根据你当前选择的模型、图像尺寸和运行设备做一次短时实测，帮助你确认当前环境下可启动的批次范围。

建议在这些情况下先做校准：

- 第一次在这台电脑上训练
- 换了模型
- 改了图像尺寸
- 不确定当前机器能承受多大批次

> 批次校准的结果是“当前环境下的实测参考值”，不会自动替你改写训练配置。

## 7.4 如何开始训练

一次完整训练通常是这样的：

1. 选择数据集
2. 选择模型
3. 设置训练参数
4. 如有需要，先做批次校准
5. 启动训练任务
6. 在任务详情或任务中心观察进度

## 7.5 训练过程中看什么

训练启动后，可以重点关注：

- 当前任务是否正常运行
- 进度是否持续推进
- 日志里是否出现明显报错
- 每轮指标是否逐步改善

如果你在训练页停留，也可以直接切换到任务详情查看当前训练；
如果离开页面，之后也可以在任务中心继续查看同一个任务。

## 7.6 训练结果会写到哪里

每次训练都会生成独立产物目录：

```text
projects/<project>/training_outputs/<dataset_name>/<run_id>/
```

常见结果包括：

- 训练配置快照
- 每轮训练指标
- 最佳权重 `best.pt`
- 最近权重 `last.pt`
- 训练曲线和可视化图片

## 7.7 停止与继续训练

### 停止训练

如果训练过程中发现参数不合适，或者当前机器需要释放资源，可以直接停止任务。

停止后，系统会尽量保留当前可恢复的训练结果，方便后续继续。

### 继续训练

如果某次训练已经产生了可继续使用的权重，可以从历史训练记录里继续训练，而不需要从头开始。

这适合：

- 上一次训练被主动停止
- 想在原有结果上继续增加轮数
- 想基于已有模型继续微调

## 7.8 常见问题

| 现象 | 处理建议 |
| --- | --- |
| 启动后立刻失败 | 先检查数据集是否完整、模型是否可用、参数是否填写合理 |
| 很快报内存或显存不足 | 先降低批次，再考虑降低图像尺寸 |
| 训练能跑但很慢 | 先减少图像尺寸、批次或训练轮数，确认流程可用后再放大 |
| 指标长时间没有改善 | 检查标签质量、类别分布和学习率设置，必要时重新做数据清洗 |
| 中途想回看状态 | 直接去任务中心查看同一个训练任务 |
